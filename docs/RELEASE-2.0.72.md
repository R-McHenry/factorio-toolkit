# Toolkit 2.0.72: an active provider chest in the starter kit

Rory, 2026-10-30: "update the starter kit to include one". The kit (`kickoff/setup_v1.py`, KIT) now
holds one active provider chest, next to the ten storage, ten requester and ten passive provider
chests. It is the output chest of the circuit auto mall (2.0.71,
`factorio-design\drafts\automall-20261030`). The mall's combinators are not in the kit: the player
makes them.

Only new runs get it, since setup_v1 runs once on a new map.
